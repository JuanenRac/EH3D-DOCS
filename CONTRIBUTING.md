# Contributing to EH3D-DOCS

Thank you for looking. A document here must say only what is true today.

1. **Say what runs and what is only planned.** A capability goes into the matrix as tested only when a test passes, and as run on a machine only when a machine moved.
2. **Before a pull request:** `python -I tools/ci_validate.py` and `python -I tools/check_links.py` must pass.
3. **Texts exist in eight languages** (English, Spanish, French, Italian, German, Chinese, Japanese and European Portuguese) in the README files, which keep the same structure.
4. Commits are written in English, small and about one thing.
