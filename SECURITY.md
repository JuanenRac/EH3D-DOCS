# Security policy

This repository holds documentation and two small checks; it installs nothing and runs nothing on a machine. A document that tells somebody to do something unsafe (for example to run a program on a machine without its limits) is a defect: please report it.

## Reporting a problem

Please report a vulnerability or an unsafe instruction privately to **electrohobby3d@gmail.com**, with the document and the passage. Do not open a public issue for it. You will get an answer as soon as possible; this is a one-person project.

Only the latest version is supported.
