# EH3D-DOCS: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| A capability matrix written by a script | The matrix says what has run and on what; a script can read versions, not whether something ran on a machine | the manifests carry the evidence of each capability in a form a script can read |
| A failing daily contract check | Several repositories it names are still being brought up to date one by one | the repositories are up to date and the warnings are zero |
| Publication of the tools as a package | They are copied into the repositories on purpose so that each one builds alone | a tool is needed by a program that does not live in the suite |
| A check of the prose of the guides | A script cannot tell if a guide is true; the links and the numbers are checked, the sentences are read | a rule of the guides can be put in a form that a script can read |
| A real release made only with these tools | No repository has done it yet and a toy repository does not show every case | a repository is released with them |
