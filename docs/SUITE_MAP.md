# The map of the suite

What each repository of the EH3D Fabrication Suite is for, and whether it exists yet. "Published" means the repository is on GitHub with its tests and CI; "Planned" means there is a design and no code that anybody can run. Nothing here has been run on a machine yet.

| Repository | Kind | State | What it is for |
|---|---|---|---|
| [EH3D-COMMON](https://github.com/JuanenRac/EH3D-COMMON) | Library | Published | What the programs share: the project container (`.eh3dproj`), the telemetry types and the colours, and the crates `eh3d-view` (the job on the table, eleven themes, the interface words in eight languages), `eh3d-archive` (jobs in ZIP archives), `eh3d-bungard-formats` (the files of the Bungard machines, with HP-GL arcs, Gerber and DXF outlines), `eh3d-controller` (the interface of the machine controllers, GRBL and a simulated one) and `eh3d-filedialog` (the Open and Save windows). It also has the height map of the table (`eh3d-levelling`) and the client of the node of the drill head (`eh3d-aux`). |
| [EH3D-CORE-LIBS](https://github.com/JuanenRac/EH3D-CORE-LIBS) | Library | Published | Readers for Gerber, Excellon and G-code that never panic and report what they could not understand. |
| [EH3D-UPDATER](https://github.com/JuanenRac/EH3D-UPDATER) | Tool | Published | Finds, installs and updates the repositories of the suite on the PC. |
| [EH3D-DOCS](https://github.com/JuanenRac/EH3D-DOCS) | Documentation | Published | This hub. |
| EH3D-SUITE-LAUNCHER | Desktop program | Planned | The central window: workspaces, projects and the other programs. |
| EH3D-TOOL-MANAGER | Desktop program | Planned | The inventory of drill bits, V-bits and routers. A first part exists: the catalogue of 115 bits with the 1/8 inch shank of the chuck, in EH3D-BUNGARD-GUI. |
| EH3D-ISOCAM | CAM program | Planned | Copper isolation toolpaths from Gerber layers. |
| [EH3D-DRILLPRO](https://github.com/JuanenRac/EH3D-DRILLPRO) | Desktop program | Published | The classic screens of the Bungard CCD drilling software in Rust: Excellon files and jobs in ZIP archives, the manual and the basic automatic tool change, buttons that answer to the pointer, sounds at the end of a job and at a tool change, on a simulator or a real machine. Panels can carry tabs on their outside, a job can go on after a stop, and the plan can follow a height map of the table. |
| [EH3D-ROUTEPRO](https://github.com/JuanenRac/EH3D-ROUTEPRO) | Desktop program | Published | The classic screens of the Bungard CCD routing software in Rust: HP-GL files (with arcs and circles), DXF drawings and Gerber outlines, multi-pass paths, on a simulator or a real machine. The outside of a panel can be cut at its tabs, a job can go on after a stop, and the cut can follow a height map of the table. |
| [EH3D-BUNGARD-GUI](https://github.com/JuanenRac/EH3D-BUNGARD-GUI) | Desktop program | Published | The modern interface of the Bungard machines: the job in 2D and in 3D on the machine, more than a hundred materials of boards, eleven themes, eight languages, recent files, Gerber and DXF outlines, a window of the machines and stations of the server; it runs on the simulator of the classic programs. It also has a catalogue of 115 bits, the calibration of the table with a simulated probe, the window of the node of the drill head with its camera, spoken voices for the notices, tabs for panels and the job that goes on after a crash. |
| [EH3D-SERVER](https://github.com/JuanenRac/EH3D-SERVER) | Service | Published | The center of the programs: it takes jobs from EH3D-DRILLPRO and EH3D-ROUTEPRO, plans them with their libraries, runs them on the machine through its node and tells every client how they go; tested against a simulator. It can check GitHub for newer releases of itself and of Studio and update them, through a helper started by systemd. |
| [EH3D-STUDIO](https://github.com/JuanenRac/EH3D-STUDIO) | Web application | Published | The configuration panel of EH3D-SERVER in the look of EH3D-BUNGARD-GUI: monitor (overview, machines by station, jobs, live events), configure (machines, users and tokens, the settings of the server) and account, in eight languages; the server serves its pages itself. Tested on a computer and looked at against a local server with simulated machines. An Updates page checks and applies the updates of the server and of Studio from the releases of GitHub. |
| [EH3D-NODE-BUNGARD](https://github.com/JuanenRac/EH3D-NODE-BUNGARD) | ESP32-S3 node | Published | Firmware that puts the RS-232 port of a Bungard CCD control unit on the network, with the machine's lamps, a spindle output and a web panel; the rules are tested on a computer and nothing has been flashed to a board. |
| [EH3D-NODE-BUNGARD-AUX](https://github.com/JuanenRac/EH3D-NODE-BUNGARD-AUX) | ESP32-S3 node | Published | The node of the drill head, with a wired network port: it measures the height of the table with a laser (the readings are filtered and a bad measure is refused with its reason), reads the speed and the temperature of the spindle, opens a protect output when the spindle is too fast or too hot, and sends the camera as RTSP (JPEG over RTP) and ONVIF like an IP camera, behind a login; the rules and the words of the network are tested on a computer, the firmware is not built and the drivers of the laser and of the temperature sensors are not written. |
| [EH3D-NODE-BUNGARD-HMI](https://github.com/JuanenRac/EH3D-NODE-BUNGARD-HMI) | ESP32-P4 touch screen | Published | A 10.1-inch touch screen meant to control a Bungard CCD machine on its own, in eight languages with spoken alerts and orders; the rules (a gate with confirmation and a hardware-stop latch, the settings file, the voice) are tested on a computer and the firmware has not been built or run on a module. It has a numeric pad and a full keyboard of each language for the settings, buttons with symbols and notices by recorded voice. |
| [ELECTRO-HOBBY-3D-UPDATER](https://github.com/JuanenRac/ELECTRO-HOBBY-3D-UPDATER) | Tool | Published | A thin dispatcher above the updaters of the four ecosystems, EH3D-UPDATER among them. |
| EH3D-LASER-CAM | CAM program | Planned | Job preparation for laser cutting and engraving. |
| EH3D-GERBERVIEWER | Viewer | Planned | A light viewer for Gerber and drill files. |
| EH3D-STENCILCAM | CAM program | Planned | Solder paste stencils from the paste layers. |
| EH3D-AUTOLEVEL | Utility | Planned | Height maps from probing and G-code correction. The height map itself (`eh3d-levelling` in EH3D-COMMON), its window in EH3D-BUNGARD-GUI and the correction of the Z of drilling and routing jobs already exist, with a simulated probe; the probe of the node of the drill head is the part that is missing. |
| [EH3D-MOTIONCNC](https://github.com/JuanenRac/EH3D-MOTIONCNC) | Desktop program | Published | Machine control after the model of PlanetCNC, over a simulated controller for now: position, jog, zeros, a G-code program with its path, menus, settings, Open and Save windows. Real controllers (GRBL first) are not connected yet. |
| EH3D-PNP-MANAGER | Desktop program | Planned | Pick-and-place assembly management. |
| EH3D-PENDANT-GUI | Touch interface | Planned | A remote manual controller for small touch screens. |
| EH3D-CAM-DEBUGGER | Desktop program | Planned | A layer-by-layer simulator and analyser of toolpaths. |
| EH3D-VISION-STUDIO | Desktop program | Planned | Camera calibration and fiducial alignment. |

The layering and the rules every repository follows are in [ARCHITECTURE.md](ARCHITECTURE.md); what has actually been tested is in [CAPABILITY_MATRIX.md](CAPABILITY_MATRIX.md).
