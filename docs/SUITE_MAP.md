# The map of the suite

What each repository of the EH3D Fabrication Suite is for, and whether it exists yet. "Published" means the repository is on GitHub with its tests and CI and a release; "Started" means the first code exists with tests that pass on a computer and there is no release yet; "Planned" means there is a design and no code that anybody can run. Nothing here has been run on a machine yet except the serial protocol of EH3D-DRILLPRO. The Release column is the newest release on GitHub. Of the twelve repositories of the PHOENIX project (electronic design) and the bridge to HYDRA-UMC, EH3D-PHOENIX-PCB and EH3D-PHOENIX-CAD have a first release; the other ten are on GitHub with no release yet, so they are "Started" or "Planned" and have "-" in that column. A window that is "unreleased" is in the repository (built with `--features gui`) and is not yet in the release of the Release column.

| [EH3D-SERVER](https://github.com/JuanenRac/EH3D-SERVER) | Service | Published | 0.1.4 | The center of the programs: it takes jobs from EH3D-DRILLPRO and EH3D-ROUTEPRO, plans them with their libraries, runs them on the machine through its node and tells every client how they go; tested against a simulator.
