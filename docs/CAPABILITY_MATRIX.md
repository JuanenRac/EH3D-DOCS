# What works and what has been run

"Tested" here means the tests of the repository pass on a computer. "Run on a machine" means a real CNC, laser or pick-and-place machine moved because of it. **Only the serial protocol of EH3D-DRILLPRO, which EH3D-ROUTEPRO shares, has moved a real machine (one Bungard CCD MTC: the reference run and the moves of each axis); no whole job has run on a machine, and nothing else of the suite has.**

| Capability | Repository | Tested | Run on a machine | Notes |
|---|---|---|---|---|
| `.eh3dproj` container: write, read, SHA-256 integrity, limits on entries | EH3D-COMMON | Yes | No | The format is in the EH3D-COMMON repository (`docs/FORMAT.md`). |
| Telemetry types of a machine (axes, spindle, states, GRBL alarm codes) | EH3D-COMMON | Yes | No | Types only; nothing produces them yet. |
| Gerber (RS-274X) reader | EH3D-CORE-LIBS | Yes | No | Not tried on a collection of real production files. |
| Excellon drill reader | EH3D-CORE-LIBS | Yes | No | Same. |
| G-code reader and modal interpreter (GRBL, Marlin, PlanetCNC) | EH3D-CORE-LIBS | Yes | No | Cutter compensation and canned cycles are reported as unsupported. |
| Find, install and update the repositories of the suite | EH3D-UPDATER | Yes | No | Tested with a fake GitHub and local repositories; it has never installed a project from the real GitHub. |
| Hand the projects of the four ecosystems over to their own updaters | ELECTRO-HOBBY-3D-UPDATER | Yes | Partly | `status` has run against a real checkout of three of the ecosystems and `install` once; the hand-over to EH3D-UPDATER has not been run against a real checkout. |
| Drilling: Excellon files, the tool table, the classic screens, the job on a simulator | EH3D-DRILLPRO | Yes | Partly | The reference run and the moves of every axis were tried on one Bungard CCD MTC; a whole drilling job has not run. |
| Routing: HP-GL files, multi-pass paths, the classic screens, the job on a simulator | EH3D-ROUTEPRO | Yes | No | It shares the protocol of EH3D-DRILLPRO; a whole routing job has not run on a machine. |
| Plan a job, keep users and machines, run it through a node with a stop and operator dialogs | EH3D-SERVER | Yes | No | Tested through its interface with jobs on the simulator; it does not terminate TLS. |
| Control link, lamps, spindle output, web panel and update with rollback of the node | EH3D-NODE-BUNGARD | Yes | No | The rules are tested on a computer and both firmware images build; nothing has been flashed to a board. |
| The configuration panel of the server: machines with their node and files, users and tokens, jobs and live events, three groups of pages by role, eight languages | EH3D-STUDIO | Yes | No | The client of the API, the rules of the forms and the languages are tested; the pages were looked at against a local server with simulated machines, never on a bench. |
| Several machines and stations at once: the answer of the server for the whole fleet, read by the programs and shown in a window | EH3D-SERVER, EH3D-COMMON | Yes | No | Tested through the interface of the server and a stand-in server; it has never watched real machines. |
| The touch screen of the machine: the gate that every move passes (confirmation, hardware-stop latch, armed link), the settings file, spoken orders and alerts in eight languages | EH3D-NODE-BUNGARD-HMI | Yes | No | The rules are tested on a computer; the firmware has not been built or run on a module and there is no link to a machine yet. |
| The firmware base that every node copies | EH3D-COMMON | Yes | No | Tested only through EH3D-NODE-BUNGARD, the one node that uses it. |
| The files of the Bungard machines: Excellon, HP-GL (with arcs, circles and scaling), tool tables, configuration; Gerber and DXF outlines as routing paths | EH3D-COMMON | Yes | No | Shared by DRILLPRO, ROUTEPRO and BUNGARD-GUI; the outlines were tried on written examples, not on a collection of real files. |
| Jobs in ZIP archives and the Open and Save windows (places, sorting, filters, replace check) | EH3D-COMMON | Yes | No | The state of the windows has no interface of its own; BUNGARD-GUI and MOTIONCNC draw it. |
| Interface of the machine controllers: GRBL on a scripted line, a simulated controller with limits, stored positions and G-code | EH3D-COMMON | Yes | No | GRBL has not been connected to a serial port; the other families are listed as not driven. |
| The job in 2D and 3D, eleven themes, eight languages, simulation at the speed of the machine, panels, board library, recent files, hole counts | EH3D-BUNGARD-GUI | Yes | No | Run on the simulator of the classic programs and on a computer; no machine has been driven from this window. |
| Machine control: position, jog, zeros, stored positions, a G-code program with pause, stop and emergency stop, menus, settings, files | EH3D-MOTIONCNC | Yes | No | Only over the simulated controller; no real controller is connected, and the emergency stop of the window is not a safety circuit. |
| Height map of the table (the grid, the surface between the points, the tilt, the text form) | EH3D-COMMON (`eh3d-levelling`) | Yes | No | The arithmetic is tested; no real table has been measured. |
| The calibration of the table in a window, with a simulated probe; the map keeps with the machine and the jobs of drilling and routing can follow its heights | EH3D-BUNGARD-GUI, EH3D-DRILLPRO, EH3D-ROUTEPRO | Yes | No | The probe is simulated; the depth of each hole and the Z of a cut follow the map in the tests of the plans, never on a machine. |
| The client of the node of the drill head: status, measure, camera as MJPEG; the node in the machine file; the window of its camera, speed and temperature, directly or through EH3D-SERVER; the same on the page of a machine of Studio | EH3D-COMMON (`eh3d-aux`), EH3D-DRILLPRO, EH3D-BUNGARD-GUI, EH3D-SERVER (`/api/v1/machines/:id/head/...`), EH3D-STUDIO | Yes | No | Tested against stand-in nodes on the network; no real node exists yet. |
| The node of the drill head: the measure of the laser, the speed and the temperature of the spindle with a protect output, the words of the network, the video as RTSP (JPEG over RTP) and ONVIF with the logins | EH3D-NODE-BUNGARD-AUX | Yes | No | The rules are tested with published vectors (MD5, SHA-1, the Digest example); the cameras OV2640 and OV5640 and the drivers of the laser (VL53L1X) and of the temperature sensors (DS18B20, NTC, MLX90614) are written but have never run; the firmware has not been flashed. |
| Tabs for the outside routing of a panel, jobs that go on after a crash, a catalogue of more than 450 bits, spoken voices (synthetic) for the end of a job and the tool change | EH3D-BUNGARD-GUI, EH3D-DRILLPRO, EH3D-ROUTEPRO | Yes | No | Tested on the simulator; the voices are not recordings of a person. |
| The update of the server and of Studio from the releases of GitHub: the page of the Studio, the API of the server and the helper that downloads, checks the SHA-256 and installs | EH3D-STUDIO, EH3D-SERVER | Yes | No | The helper is tested with GitHub and systemd replaced by stand-ins; it has never updated a real installation. |
| The keyboards of each setting of the touch screen (a numeric pad with the range of the setting, a full keyboard of each language), buttons with symbols and notices by recorded voice | EH3D-NODE-BUNGARD-HMI | Yes | No | Tested as rules on a computer; the firmware has not been built. |
| The programs of the suite found by their manifests, started and started again if they fail, the project file with the SHA-256 of its files, the recent projects | EH3D-SUITE-LAUNCHER | Yes | No | A library and a command line tested on a computer, with a real child process for the restarts; there is no window and no discovery of machines on the network. |
| The tool crib: tools, wear counters with limits, JSON and CSV storage, starting feeds and speeds by material | EH3D-TOOL-MANAGER | Yes | No | The numbers of the feeds and speeds are typical values that have not been tried on a machine; no program reads the crib yet. |
| Gerber layers and drill files as an SVG picture; the narrowest track, the smallest gap, layers that do not line up, holes outside the copper | EH3D-GERBERVIEWER | Yes | No | Tried on written examples, not on a collection of real production files; there is no window. |
| Isolation paths of the copper of a Gerber layer: the exact distance on a grid, several passes, gaps the tool cannot cut, G-code | EH3D-ISOCAM | Yes | No | The distance is checked against a brute force and the paths against the radius of the tool; no board has been milled. |
| Raster engraving of an image with dithering, dynamic power and overscan, and a power-against-feed grid | EH3D-LASER-CAM | Yes | No | No laser has burned anything with it. |
| Solder paste stencils: openings shrunk, rounded and compensated for the kerf, aspect and area ratios, G-code and HP-GL | EH3D-STENCILCAM | Yes | No | Polygon and macro pads are not turned into openings; no stencil has been cut. |
| Correction of the Z of a G-code program with the height map of the table, bilinear or bicubic | EH3D-AUTOLEVEL | Yes | No | Tested with simulated maps; arcs are refused; no real table has been corrected. |
| Pick and place: KiCad and CSV position files, feeders, the order of the placements for one to six nozzles, the bottom side mirrored | EH3D-PNP-MANAGER | Yes | No | No machine has placed a part and there is no camera. |
| Time of a G-code program with the acceleration of the machine, alerts for rapid moves into the material, moves outside the table, cuts with the spindle off and heads over clamps | EH3D-CAM-DEBUGGER | Yes | No | The time is an upper bound; there is no 3D simulation. |
| Round fiducial marks in an image, the scale of the camera, the distortion of the lens, the turn and the shift of a board | EH3D-VISION-STUDIO | Yes | No | Tried on pictures drawn by the tests, not on photographs of real boards; there is no live camera. |
| A program that was running goes on from the line it had reached after a crash | EH3D-MOTIONCNC | Yes | No | Over the simulated controller only; nothing is sent to a controller until the operator answers. |
| The phone apps: the fleet and its jobs in real time, the emergency stop, the job in 2D and in an isometric view, the camera of the drill head through the server, updates from GitHub | EH3D-ANDROID-CONTROL, EH3D-IOS-CONTROL | Yes | No | The rules are tested on a computer (and the iPhone ones on a Mac in the CI); neither app has run on a phone or against a real server, and the pictures of their screens are drawings. |
| 2D geometry (offsets, booleans) and HP-GL in the readers | | No | No | Planned in EH3D-CORE-LIBS; EH3D-ISOCAM and EH3D-STENCILCAM make the offsets they need on their own. |
| The programs that do not exist yet (the general purpose touch screen, the pendant, the real controllers for machine control) and the windows of the programs that are libraries and command lines | | No | No | Planned; see [SUITE_MAP.md](SUITE_MAP.md). |
